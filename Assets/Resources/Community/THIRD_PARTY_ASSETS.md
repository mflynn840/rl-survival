# Community art sources

The files in this folder are selected, unmodified runtime meshes from public-domain community packs. They are kept in `Resources` because the procedural Unity scene instantiates them by name.

| Source | Files used | License | Source URL |
| --- | --- | --- | --- |
| Kenney Nature Kit 2.1 | `KenneyNature/*.fbx` — palms, pines, oak, bushes, grass, flowers, rocks, fences, logs | CC0 1.0 | https://kenney.nl/assets/nature-kit |
| KayKit Character Pack: Adventurers 1.0 | `KayKit/RogueHooded.fbx`, `KayKit/Barbarian.fbx` | CC0 1.0 | https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0 |

Kenney Nature Kit archive SHA-256: `fa7974a0d342bfe63c38664ba9f8ec1a4aab8ea25f099bdc56870e33588c4d9d`.

The level layout, lighting, palette, materials, gameplay models, and implementation are original work in this project. These packs are used as stylized building blocks, without copying the reference images in `Assets/Art`.
